# 삼국지 천하결전 덱 보드 (SamCheon_Deck)

삼국지 천하결전 덱을 무한 캔버스 위에 덱 단위로 펼쳐두고 정리하는 웹앱.
빌드 도구 없이 순수 HTML/CSS/JavaScript(ES 모듈)라서 GitHub Pages에 파일 그대로 올리면 동작한다.

**웹에서 열기:** https://nuclyee72.github.io/SamCheon_Deck/

[가계도 메이커(Gagedo)](https://github.com/nuclyee72/Gagedo)의 캔버스 조작(팬/줌·드래그·스냅·겹침 방지)과
관계선 코드를 가져와 만들었다(`src/lib/`, `base.css`).

## 로컬에서 실행하기

`src/main.js`가 ES 모듈이라 `index.html`을 파일로 바로 열면 동작하지 않는다. 로컬 웹서버로 연다.

```bash
python -m http.server 8080
# 또는
npx serve .
```

그다음 http://localhost:8080/ 을 연다.

## 기능

- **템플릿 ▾ → 🃏 덱**: 빈 덱 양식(덱 이름·전형·비고 + 장수 3명)을 화면 가운데 빈 자리에 만든다.
- **덱 옮기기**: 덱 맨 위 헤더(⠿ 쪽)를 잡고 끈다. 덱끼리는 겹치지 않고, 휴지통에 놓으면 삭제.
- **덱 이름**: 제목처럼 크게. 이름 오른쪽에 장수 1·2·3의 병종이 "말•창•활"처럼 자동으로 붙는다
  (창/말/활/방 — `catalog.js` troopTypes의 `short`, 병종을 안 고른 장수는 "?").
- **장수 칸**: 초상화(클릭/끌어다 놓기 → 크롭), 초상화 오른쪽 위 "병부" 마크(클릭으로 켜고 끔),
  병종·병종 전통, 전법 3개(전법 1은 노란 테두리, 전법 2·3은 오른쪽 "☆ 필수"를 누르면 필수 전법 ★), 병법 3개, 장비·탈것 옵션(1옵/2옵마다 그 옵
  후보 중 추천을 개수 제한 없이 칩으로), 속성치(무력/지력/통솔/선공 중 선택, "텍스트박스"를 고르면 직접 입력).
  장수 3명의 같은 파트는 줄이 맞춰진다.
- **대체 전법**: 전법 칸 오른쪽 ▶를 누르면 대체 전법 목록이 오른쪽에 펼쳐진다(추가/삭제 가능, 개수는 ▶ 옆에 표시).
- **덱끼리 관계**: 툴바 "관계 ▾"에서 관계 템플릿(카운터 / 화살표 / 기타(선))을 고르고 시작 덱 → 끝 덱을
  차례로 누른다. 선을 누르면 라벨·색·선 종류·방향 뒤집기·양방향·삭제를 고칠 수 있다.
- **수정 / 보기**: 툴바 맨 앞에서 전환. 보기 모드는 수정용 버튼을 숨기고 셀렉트·입력칸을 그냥 박스로
  보여준다. 병부·필수(★)는 켜진 것만, ▶는 대체 전법이 있는 전법에만 보인다. 덱은 못 옮기고(덱 위에서
  끌어도 화면 이동), 실행취소·삭제 단축키도 막힌다.
- **표시(많이/보통/적게)**: 많이 = 전부, 보통 = 장수·병종/전통·전법(+비고), 적게 = 장수만(보기 모드에서는 전형도 숨김).
  관계선은 표시 단계를 바꿔도 같은 자리에 있다.
  길어진 덱이 아래 덱을 밀어내도, 덱을 옮기지 않은 채 원래 표시로 돌아오면 원래 자리로 돌아간다.
- **덱 ⋯ 메뉴**: 템플릿으로 저장 / 복제 / 이 덱 JSON 내보내기 / 위치 잠금 / 삭제.
- **템플릿 메뉴**: 맨 위 "🃏 덱"·"📋 리스트"로 새로 만들거나, 저장해둔 템플릿을 다시 넣거나 ×로 삭제.
- **리스트**: 시즌 제목(덱 이름 크기) + 장수 목록 + 전법 목록(각각 한 줄에 6칸, 맨 끝 +로 계속 추가,
  마우스를 올리면 ×로 빼기). 덱처럼 옮기기·관계선·⋯ 메뉴(템플릿 저장·복제·잠금·삭제)를 그대로 쓴다.
  리스트의 장수/전법 칸을 누르면 이름이 같은 장수/전법이 보드 전체(덱·다른 리스트)에서 강조되고
  (대체 전법에만 있으면 ▶가 강조됨), 다시 누르거나 빈 배경·Esc를 누르면 꺼진다(보기 모드에서도 됨).
- **이름 자동완성**: 장수 이름·전법 칸에 보드에서 이미 쓴 이름이 후보로 뜬다(강조가 어긋나지 않게).
- **💾**: 보드 전체 JSON 내보내기, 보드 또는 덱 JSON 가져오기(초상화 포함).

### 화면 조작

| 동작 | 방법 |
| --- | --- |
| 화면 이동(팬) | 빈 배경을 드래그 (보기 모드에서는 덱 위에서도) |
| 확대/축소 | 마우스 휠 / 두 손가락 핀치 |
| 덱 이동 | 덱 헤더(⠿ 쪽)를 드래그 (터치에서는 덱 이름을 끌어도 됨) |
| 실행취소/다시실행 | 툴바 ↶ ↷ 또는 Ctrl+Z / Ctrl+Y (입력칸 밖에서) |
| 한 화면에 넣기 | 툴바 ⛶ |

## 공개 보기 / 편집 / 게시

- **공개 보기**(그냥 사이트 주소): 리포지토리의 `data/board.json`을 읽어 보기 모드로만 보여준다. 방문자 브라우저에는
  아무것도 저장하지 않고, 수정/보기 전환·💾·템플릿·관계 메뉴도 없다.
- **편집**: 주소 끝에 `?edit`를 붙이거나(예: `…/SamCheon_Deck/?edit`) localhost에서 연다. 지금까지처럼 그
  브라우저에 저장하며 고친다. 그 브라우저에 저장된 보드가 없으면 게시본에서 시작한다.
  localhost에서 방문자 화면을 미리 보려면 `?public`.
- **게시**: 편집 화면에서 💾 → "게시용 board.json 저장" → 받은 파일을 `data/board.json`에 덮어쓰고 push.
  1~2분 뒤 공개 보기에 반영된다. 다른 컴퓨터에서 이어서 고칠 때는 💾 → "게시본 불러오기".
- 오른쪽 위에 보드 수정일(마지막으로 고친 날)과 크레딧이 보인다. 공개 보기에서는 게시된 보드의 수정일.
- 리포지토리가 공개라서 `data/board.json`(초상화 포함)도 누구나 받을 수 있다 — 공개해도 되는 내용만 게시.

## 데이터 저장

- 모든 덱·관계선·템플릿은 **그 브라우저의 IndexedDB(`samgukDeckDB`)에만** 자동 저장된다. 서버로는 아무것도
  보내지 않는다. 그래서 다른 기기·다른 브라우저에서는 보이지 않는다.
- 옮기거나 백업하려면 💾 → "보드 전체 JSON으로 내보내기" 한 파일을 다른 곳에서 "가져오기".
- 덱·리스트·템플릿 어디에서도 안 쓰는 초상화 이미지는 페이지를 열 때 자동으로 정리된다.
- 브라우저의 사이트 데이터를 지우거나 시크릿 모드를 쓰면 사라질 수 있으니 주기적으로 내보내기를 권장.

## 셀렉트 선택지 바꾸기

`src/catalog.js`에서 전형 / 병종(+요약 글자 `short`) / 병종 전통 / 병법 / 장비 옵션(1옵·2옵 후보) /
탈것 옵션 / 속성치 / 관계 템플릿을 고친다(속성치 외에는 지금 예시 값).
덱에는 항목의 `id`가 저장되므로 `name`은 언제든 바꿔도 되고, `id`를 바꾸거나 지우면 그 값을 쓰던 칸에
"(삭제된 항목: id)"로 표시된다.

## GitHub Pages 배포

`main` 브랜치 루트(`/`)를 GitHub Pages로 내보낸다(Settings → Pages). push하면 1~2분 뒤 반영된다.
